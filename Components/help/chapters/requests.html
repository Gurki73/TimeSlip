📆 Kapitel 7 – Urlaubsanträge

Auch wenn Urlaubsanträge oft formlos eingereicht werden – per Post-it, Fahrstuhlgespräch oder E-Mail ohne Struktur – wollen wir sie hier ordentlich erfassen. Das Formular ist in zwei Tabs unterteilt: "Urlaubsantrag stellen" und "Urlaubsanträge verwalten".

  • Urlaubsanträge können verschiedene Abwesenheitsarten haben
  • Das System prüft automatisch auf Regelverstöße
  • Die zweite Ansicht erlaubt das Genehmigen oder Ablehnen

📝 Urlaubsantrag stellen

  1. Mitarbeiter auswählen:
    Im Dropdown wird Name oder Alias gewählt. Ist ein Urlaubsanspruch hinterlegt, wird dieser angezeigt. Das Antragsdatum wird automatisch ausgefüllt.
  2. Abwesenheitsart auswählen:
    Zur Auswahl stehen: Urlaub, Dienstreise, Home Office, Schule, Sonderurlaub, Überstunden abbauen, Krank, Unbezahlt. Danach erfolgt die Eingabe von Start- und Enddatum via DatePicker. Bei Einzeltagen kann zusätzlich ausgewählt werden: ganztägig, vormittags, nachmittags.
  3. Optionaler Kommentar:
    Ein Freitextfeld, z.B. "Mein Sohn spielt die Hauptrolle im Schultheaterstück."
  4. Speichern nicht vergessen!
    Ohne Speichern gehen Eingaben verloren. Direkt beim Speichern prüft das System, ob der Antrag gegen definierte Regeln verstößt – z. B. ob zu viele Personen gleichzeitig abwesend sind.

✅ Urlaubsanträge verwalten

Alle eingereichten Anträge werden in einer übersichtlichen Tabelle dargestellt. Diese kann nach Monat, Status oder Mitarbeiter gefiltert werden.

  • Dringende Anträge (Abwesenheitsbeginn innerhalb von drei Arbeitstagen) können nicht weggefiltert oder nach unten sortiert werden.
